# Data licensing

The code in this repository is MIT-licensed. The data it uses belongs to its publishers. This file summarizes their terms; it is not legal advice, so check each publisher's terms for your use.

| Data | Publisher | Terms (summary) |
|---|---|---|
| FHFA House Price Index | Federal Housing Finance Agency (U.S. government) | U.S. government work; generally public domain. Cite FHFA. |
| CPI series, Treasury yields | BLS, Federal Reserve Board (U.S. government) | Public domain. Cite the agency. |
| ACS tables | U.S. Census Bureau | Public domain. Cite the Census Bureau. |
| FRED (delivery) | Federal Reserve Bank of St. Louis | Follow FRED's terms of use and each series' own copyright notes. |
| Freddie Mac PMMS | Freddie Mac | Copyrighted; FRED marks it "citation required." Cite Freddie Mac. |
| Zillow ZHVI / ZORI | Zillow Group | Zillow Research data may be used with attribution to Zillow; see Zillow's terms. |
| Historical returns | Aswath Damodaran, NYU Stern | Freely published for educational use; cite the source. |
| S&P Cotality Case-Shiller (seed data only) | S&P Dow Jones Indices | Copyrighted; FRED notes reproduction is prohibited without permission. Removed from the published data by the first pipeline run, which uses FHFA instead. |

If you publish derived data or results, keep the citations in SOURCES.md with them.
